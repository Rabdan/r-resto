# ТЗ и инструкция по верстке фронтенд-интерфейса официанта (POS Terminal)

Данный документ представляет собой строгое техническое задание и промпт-инструкцию для AI-агента (генерации компонентов Svelte/React + Tailwind CSS).

---

## 1. Глобальное состояние приложения (State Schema)

```typescript
type DeviceStatus = 'unregistered' | 'registered';

interface AppState {
  device: {
    status: DeviceStatus;
    code: string; // 6-значный код активации
    waiterName: string; // Например, "Цыцыгма"
    assignedHalls: Hall[];
    activeHallId: string;
  };
  filterTab: 'active' | 'closed';
  prechecks: PreCheck[];
  activePrecheckId: string | null;
}

interface Hall {
  id: string;
  name: string;
  colorHex: string; // Цвет шапки (напр. #1E293B, #065F46)
}

interface Guest {
  id: string;
  name: string; // "Гость 1", "Слава"
  isPaid: boolean;
  paymentMethod?: 'cash' | 'cashless';
}

interface OrderItem {
  id: string;
  guestId: string;
  title: string;
  price: number;
  quantity: number;
  isCustom?: boolean; // Произвольный товар
}

interface PreCheck {
  id: string;
  number: number;
  createdAt: string;
  paidAt?: string;
  settledBy?: string;
  guests: Guest[];
  items: OrderItem[];
  status: 'active' | 'closed';
}

```

## 2. Экраны и компонентная структура

### Экран 0: Регистрация неавторизованного устройства , если бекенд ответил. что устройства нет в списке (нет токена)

Показывается, если `device.status === 'unregistered'`.

* **Компоновка**: Центрированная карточка на темном фоне.
* **Элементы**:
* Заголовок: `Привязка терминала`.
* Блок 6-значного кода: крупный моноширинный шрифт ($36\,\text{pt}$), межбуквенный интервал.
* Информационное сообщение: `"Покажи этот код администратору"`.
* Анимированный индикатор ожидания соединения (Spinner / Pulse).



---

### Экран 1: Главный рабочий экран , устройство зарегистрировано по коду ключу, и назначен официант админом

#### 1.1. Шапка (Header)

* **Динамический фоновый цвет**: Задается через `style="background-color: {activeHall.colorHex}"`.
* **Левая часть**: Текст `Привет, {device.waiterName}` (Font-weight: 600).
* **Правая часть**:
* Если `assignedHalls.length > 1`: Dropdown/Select выбора зала.
* Если `assignedHalls.length === 1`: Статичный лейбл названия зала.



#### 1.2. Переключатель фильтров (Tabs)

* Две кнопки во всю ширину с четким визуальным переключением активного состояния:
* `[ Активные (пречеки) ]`
* `[ Закрытые ]`



#### 1.3. Список чеков / пречеков (List View)

При выборе вкладки **"Активные (пречеки)"**:

* Карточка чека содержит:
* Номер пречека (`Пречек №104`).
* Сумма: Рассчитывается суммарно по всем нерасплаченным гостям.
* Имя первичного гостя: `{precheck.guests[0].name}` (например, `Гость 1 / Слава`).
* Статус сплита (например, `Гостей: 2`).



При выборе вкладки **"Закрытые"**:

* Карточка закрытого чека (Read-only):
* Номер чека + Время оплаты (`19:42`).
* Полная сумма + Тип оплаты (`Безнал` / `Наличные`).
* Имена всех расплаченных гостей.
* Кем рассчитан: `{precheck.settledBy}`.



#### 1.4. Нижняя плавающая кнопка (Sticky Footer)

* Кнопка во всю ширину: `[ ➕ Создать новый пречек ]` (Высота $56\,\text{px}$, фиксирована внизу экрана).

#### 2.1. Шапка редактора

* Поле ввода имени первого гостя: Клик активирует инлайн-редактирование текста (`<input>` без рамок).

#### 2.2. Выдвижная шторка заказа (Pull-down Drawer)

* **Свернутое состояние**: Узкая полоса с итогом: `{Count} поз. — {TotalSum} ₽`. Иконка `Expand/Drag`.
* **Механика Жеста**:
* Свайп/оттягивание пальцем вниз разворачивает шторку поверх плиточного меню (Overlay).
* В развернутом состоянии отображается полная таблица: Наименование, Кол-во, Цена, Сумма, Кнопки `[+]`/`[-]`.



#### 2.3. Зона меню (Menu Area)

* **Категории**: Горизонтальный скролл (`overflow-x: auto`), кнопки-табы.
* **Плитка товаров (Grid 2 колонки)**:
* Каждая карточка: Название, Цена.
* **Красный балун (Badge)**: В верхнем правом углу карточки, если позиция есть в чеке. Показывает суммарное количество этого товара у текущего пречека.

Одинарный клик по плашке: $+1$ (появляется красный балун).Long-press (удержание 0.3 сек) или клик по самому балуну: раскрывает на плашке быстрые микро-кнопки [ − ] и [ + ].


* **Специальная плашка "Произвольный товар"**:
* При клике открывается Modal:
1. Наименование (Text Input).
2. Количество (Number Input / Счётчик).
3. Цена (Numeric Numpad).


* Потверждение добавляет позицию с флагом `isCustom: true` в активный чек.



#### 2.4. Подвал (Footer Bar)

* Три кнопки:
1. `[ 🖨️ Печать ]` — формирование предчека на принтер.
2. `[ ➕ Гость ]` — логика сплита (см. Раздел 3).
3. `[ 💳 Оплата ]` — переход к процессу расчета.

## 3. Интерактивная механика разделения чека (Split Logic)

При нажатии `[ ➕ Гость ]`:

1. В список гостей добавляется `Гость 2` (с возможностью редактирования имени).
2. На экране разворачивается интерфейс распределения позиций (Drag-and-Drop / Tap-to-move):

```
                       [ СПЛИТ ПОЗИЦИЙ ]
 [ 👤 1: Слава ]                      [ 👤 2: Вася ]
  • Борщ (1 шт)                         (Перетащите сюда)
  • Стейк (2 шт)    ====== Drag ======>

```

### Правила переноса элементов:

1. **Количество = 1**: Позиция целиком переносится на Гостя 2.
2. **Количество = 2**: Автоматически расщепляется — 1 шт остается у Гостя 1, 1 шт переходит Гостю 2.
3. **Количество > 2**: Вызывается диалоговое окно (Numpad): *"Укажите количество для переноса другому гостю (1..N)"*.

## 6. Требования к реализации UI (для AI Coder)

1. **Адаптивность**: Строго Mobile-First (ориентация портретная, оптимизация под $375\,\text{px} - 430\,\text{px}$ ширины экрана смартфона).
2. **Touch Target**: Размер всех нажимаемых элементов (кнопки, плашки товаров, табы) — не менее $48 \times 48\,\text{px}$.
3. **Animations**:
* Pull-down шторка заказа: CSS transition `transform 0.3s ease-in-out` или `framer-motion` / `svelte/transition`.
* Балуны количества: анимация появления `scale(0) -> scale(1)`.


4. **Обработка ошибок**: нерасплаченный пречек не закрывается, остается в списке активных, пока не нажмется оплата всех гостей. незакрытый пречек может закрыть только администратор из интерфейса администратора
